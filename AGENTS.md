# AGENTS.md

Kodanuki is a spectral path-tracer for a custom SDF based file format.
A minimal core defines how the renderer works. Plugins plug into
extension points to provide features or optimizations.

Read `target/docs/index.md` to find out more about the renderer.

## Agent Rules

- always ask the developer if something is ambiguous or unclear
- always keep changes minimal and simple
- always keep answers concise
- never change `target/docs/` except when asked
- never `git commit` except when asked
- never `git push` even when asked, signal the developer instead
